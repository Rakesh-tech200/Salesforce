Phase 2: Record types and custom fields
You'll build the customer-facing data model: Lead, Contact, Account, Opportunity, Campaign, Task and Event.
Two rules for this phase
Record Type Name (API) must be exactly Retail and Wholesale everywhere. Formulas, flows and Apex later look them up by these names.
Validation rules for these objects come in Phase 5, not now.
For every field in this phase, the wizard is: Object Manager → [object] → Fields & Relationships → New → pick type → Next → enter Label, Field Name and details → Next → (field-level security: leave defaults) → Next → (page layouts: as stated per step) → Save & New. For the last field, click Save.

Step 2.5: Campaign
2.5.1 Give yourself the Marketing User checkbox
Creating campaigns requires it.
Setup → Users → Users → click your name → Edit.
Tick Marketing User, then Save. This uses one of your two Marketing User licences, so one stays free for the Marketing test user later.
2.5.2 Create the "Active This Month" formula
Object Manager → Campaign → Fields & Relationships → New → Formula.
Label: Active This Month, Field Name: Active_This_Month, Return type: Checkbox.
Formula:
AND(
  NOT(ISPICKVAL(Status, "Aborted")),
  NOT(ISBLANK(StartDate)),
  StartDate <= ADDMONTHS(DATE(YEAR(TODAY()), MONTH(TODAY()), 1), 1) - 1,
  OR(ISBLANK(EndDate), EndDate >= DATE(YEAR(TODAY()), MONTH(TODAY()), 1))
)
Check Syntax, add it to the Campaign Layout, Save.
This means a campaign counts when it starts on or before the last day of this month, ends on or after the first day (or has no end date), and isn't Aborted. A campaign with no Start Date never counts.
2.5.3 Create the list view
App Launcher → Campaigns → list view dropdown → New.
List Name: Campaigns Active This Month, All users.
Filter: All campaigns and Active This Month equals True. Save.

Step 2.7: Tidy System Administrator's record-type choices
If the New Account or New Opportunity screen offers --Master-- or Master as a record type, remove it.
Setup → Profiles → System Administrator → Object Settings → Accounts → Edit.
In the Record Types and Page Layout Settings section, make sure only Retail and Wholesale are selected. Set Retail as default. Remove --Master-- if it's listed.
Save. Repeat for Opportunities.
If the screen won't let you remove Master, skip this step and don't worry about it.
